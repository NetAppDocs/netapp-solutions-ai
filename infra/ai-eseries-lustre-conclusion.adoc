= Lustre with NetApp E-Series Storage - Additional information
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Lustre with NetApp E-Series Storage delivers a validated, scalable parallel file system for AI and HPC workloads using a repeatable building block architecture with NetApp E-Series all-flash arrays. Use the links below for related documentation, tools, and software as you plan or expand a deployment.
