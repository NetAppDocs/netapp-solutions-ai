== NetApp XCP — Core Value

XCP is the mobility layer that decouples data location from compute location. A single configuration switch (`xcp++_++copy++_++destination`) determines whether prepared data and model artifacts land in NetApp ONTAP S3 or a LustreFS high-performance tier, with `model++_++training`, `fine++_++tuning`, and `inferencing` automatically reading from and writing to the same destination.
