== Executive summary

Lustre with NetApp E-Series Storage combines the open-source Lustre parallel file system with NetApp EF-Series block storage to provide a simple, reliable, and scalable storage foundation for data-intensive workloads. The solution uses a repeatable building block design in which each building block consists of two OSS/MDS server nodes in a two-node high availability (HA) cluster, two E-Series all-flash arrays, backend connectivity over NVMe-oF, and a separate high-speed fabric for Lustre networking (LNet). A base building block provides the management service (MGS), metadata targets (MDTs), and object storage targets (OSTs). Additional building blocks scale capacity and aggregate performance linearly.

Lustre with NetApp E-Series Storage is deployed using Ansible automation, which is hosted on GitHub (the ansible-lustre collection is available from link:https://github.com/NetApp/ansible-lustre/tree/release/1.0.0[NetApp's GitHub^]). NetApp-built Lustre RPM packages are available from link:https://github.com/NetApp/netapp-lustre/tree/master[netapp-lustre^]. Supported operating system, kernel, Lustre, firmware, and driver versions change over time. Refer to link:https://imt.netapp.com/imt/#welcome[NetApp Interoperability Matrix Tool (IMT)^] as the authoritative source. Search for *E-Series Lustre* in IMT to find supported software and hardware combinations for the deployment.
