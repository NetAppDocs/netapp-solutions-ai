== NetApp intelligent data infrastructure

NetApp intelligent data infrastructure is NetApp's current approach to data management. It brings data storage, data services, and workload operations together across on-premises systems and the major public clouds, so organizations can manage, protect, secure, and access their data the same way wherever it lives. It builds on the NetApp Data Fabric concept used in earlier editions of this report.

For MongoDB, this means that the ONTAP data management capabilities used in this report, such as Snapshot copies, clones, and replication, apply the same way to databases on physical servers, virtualized infrastructure, and cloud instances.

[NOTE]
Product names and versions in this report reflect the original validation and might differ from current NetApp offerings.

== NetApp All Flash FAS

NetApp All Flash FAS (AFF) is a family of enterprise all-flash storage systems that run ONTAP. The current AFF portfolio includes A-Series systems for performance-sensitive workloads and C-Series systems for capacity-optimized flash. The validation in this report used an AFF-A30, and the same ONTAP capabilities are available on current AFF models.

AFF provides the following capabilities for MongoDB:

* Run latency-sensitive databases on flash with predictable response times.
* Reduce the flash capacity required by using inline data efficiency, including deduplication, compression, and compaction. Actual savings depend on the data in your deployment.
* Scale up or scale out as a cluster and move data nondisruptively between nodes.
* Protect data with NetApp Snapshot copies, SnapRestore, and SnapMirror replication, which are built into ONTAP.
* Manage systems with ONTAP System Manager and automate operations through the ONTAP REST API.

For more information about AFF, see the link:http://www.netapp.com/us/products/storage-systems/all-flash-fas/[NetApp AFF^] product page.

== Cloud Volumes ONTAP and Amazon FSx for NetApp ONTAP

NetApp delivers ONTAP in the public cloud as a managed service or as software that you deploy yourself, so the same ONTAP data management used on the AFF array is available to MongoDB in AWS. This report refers to two options:

* Amazon FSx for NetApp ONTAP is a fully managed AWS service built on ONTAP. AWS operates the file system, and you manage volumes, Snapshot copies, clones, and SnapMirror relationships with ONTAP tools, the AWS console, or the ONTAP REST API.
* NetApp Cloud Volumes ONTAP, formerly ONTAP Cloud, is a software-defined ONTAP instance that you deploy and manage in your own AWS account. It is also available in other public clouds.

Both options provide the ONTAP capabilities used in this report: Snapshot copies, FlexClone volumes, SnapMirror replication, and data efficiency features such as deduplication, compression, and compaction. In this solution, either option can be the SnapMirror destination for backup and disaster recovery from the on-premises AFF array, and the source for dev/test clones of MongoDB in the cloud.

The original validation used ONTAP Cloud, now named Cloud Volumes ONTAP. Confirm sizing, performance, and feature availability for the option and version you choose.

== NetApp Console

NetApp Console, formerly OnCommand Cloud Manager, Cloud Manager, and BlueXP, provides a single control plane for managing data across on-premises and cloud ONTAP environments. It is used to deploy and manage Cloud Volumes ONTAP, and to discover and manage Amazon FSx for NetApp ONTAP and on-premises ONTAP systems.

NetApp Console provides the following key features:

* Simplifies configuration and deployment of Cloud Volumes ONTAP.
* Offers a central point of control for ONTAP systems on-premises and in the cloud.
* Sets up and monitors SnapMirror replication between the on-premises AFF array and cloud ONTAP for backup and disaster recovery.
* Provides backup and recovery services for ONTAP volumes.
* Supports hybrid environments that include on-premises ONTAP, Cloud Volumes ONTAP, and Amazon FSx for NetApp ONTAP.

== NetApp SnapCenter and Snap Creator Framework

Snap Creator Framework uses NetApp Snapshot technology to provide application-consistent data protection for both physical and virtualized environments. It provides a centralized solution for backing up critical information and integrates with existing application architectures to support data consistency and reduce operating costs. It can also invoke remote replication for disaster recovery. For virtualized MongoDB deployments, Snap Creator provides instant backup and recovery of MongoDB VMs and databases, and it can create rapid clones of the virtualized MongoDB environment for dev/test and QA use.

NetApp SnapCenter is the current successor to Snap Creator Framework. SnapCenter is NetApp's unified, scalable software for application-consistent data protection. It uses ONTAP Snapshot, SnapMirror, and FlexClone technologies to back up, restore, and clone application data and to replicate it for disaster recovery. SnapCenter is the recommended starting point for new deployments.

SnapCenter protects applications through plug-ins. Confirm that a MongoDB plug-in is available for your SnapCenter version before you plan a deployment. If one is not available, script ONTAP Snapshot, FlexClone, and SnapMirror operations through the ONTAP REST API to achieve the same backup, clone, and replication workflow.

[NOTE]
The validation procedures in this report used Snap Creator Framework. The backup, restore, and clone steps therefore reflect Snap Creator. Adapt them if you use SnapCenter or ONTAP REST API scripts.
